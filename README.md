# Online Car Rental System

## Project Overview

This project is a Python-based Online Car Rental System developed using Object-Oriented Programming (OOP) concepts.

The application allows customers to rent cars on an hourly, daily, or weekly basis while enabling the rental company to manage inventory and generate rental bills automatically.

---

## Business Problem

A car rental company requires an online platform where customers can:

- View available cars
- Rent cars hourly, daily, or weekly
- Request multiple vehicles
- Return rented vehicles
- Receive an automatically generated bill

The company should also be able to manage available inventory and validate rental requests.

---

## Features

### Customer Features

- View available cars
- Rent cars on an hourly basis
- Rent cars on a daily basis
- Rent cars on a weekly basis
- Return rented cars
- Receive automated billing

### Rental Company Features

- Display available inventory
- Validate rental requests
- Track rented vehicles
- Calculate rental charges
- Manage vehicle stock

## Sample Workflow

1. Customer views available cars.
2. Customer selects rental type.
3. System checks inventory.
4. Rental request is approved.
5. Customer returns vehicle.
6. System generates final bill.
